# 🛒 E-Commerce Data Analysis Project

## 📌 Description
This project focuses on analyzing an E-Commerce dataset collected from Kaggle using Microsoft Excel and SQL. The project includes data cleaning, duplicate removal, dashboard creation, pivot table analysis, data visualization, and SQL-based validation of analytical results.

The main objective of this project is to transform raw business data into meaningful insights using Excel dashboards and SQL queries.

---

## 🚀 Features
- Data cleaning and preprocessing
- Duplicate record removal
- Pivot Table analysis
- Interactive dashboards using slicers
- Sales and revenue analysis
- SQL query validation
- Business insights generation

---

## 🛠️ Technologies Used
- Microsoft Excel
- SQL
- Kaggle Dataset
- Pivot Tables
- Charts & Slicers
